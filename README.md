# Shaiya2

Proyecto de MMORPG inspirado en la esencia de Shaiya y desarrollado desde cero.

## Arquitectura

- Client: Unity
- Server: .NET
- Shared: protocolo y modelos compartidos
- Database: PostgreSQL
- Networking: LiteNetLib
